About free AI.

Orbit uses Pollinations Classic, which serves GPT-OSS 20B for free without an account, login, or API key.

◎Messages and extracted text from text/PDF attachments are sent to Pollinations. Weather questions use Open-Meteo; your chosen city or browser-approved location is sent there to retrieve forecasts.

Anonymous use is limited to one text request every 30 seconds per IP address. This limit is shared by people on the same network.

The token meter estimates the active chat’s context from text length; it is not exact tokenizer or API usage. The model context window is 131,072 tokens, but Pollinations may enforce different limits. The request rate limit is separate.
